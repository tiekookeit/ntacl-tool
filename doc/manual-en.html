ntacl_tool

A command-line utility for inspecting and changing NT ACLs through Samba, with both interactive and direct parameter-based workflows.

Manual Page / Quick Start

What It Is

ntacl_tool reads and updates NT security descriptors stored as SDDL on Samba-managed paths.

Use it when you need safe ACL staging, permission changes, inheritance control, and repeatable CLI operations.

Who It Helps

Sysadmins, Samba/AD operators, file server maintainers, and anyone automating folder permission changes.

Core Mode Split

interactive for guided editing.

show for inspection.

set for direct, script-friendly changes.

Why This Tool Exists

Working with NT ACLs directly through SDDL is precise but cumbersome. ntacl_tool provides a friendlier operational layer on top of samba-tool ntacl get --as-sddl and samba-tool ntacl set.

It helps with three common needs:

  • Inspect the current ACL in a readable format.
  • Modify permissions in a staged way before applying them.
  • Run direct changes from scripts without opening the interactive menu.

Requirements

  • python3
  • samba-tool from samba-common-bin
  • wbinfo from winbind
sudo apt update
sudo apt install -y python3 samba-common-bin winbind

Command Layout

ntacl_tool.py interactive PATH
ntacl_tool.py show PATH [--json]
ntacl_tool.py set PATH [OPTIONS]
The set command does not apply changes unless you pass --apply. Use --dry-run to review the final ACL first.

Interactive Mode

Use interactive mode when you want a guided menu and a visible staging area before applying changes.

python3 ntacl_tool.py interactive /srv/shares/finance/private

From the menu you can:

  • Disable inheritance and keep inherited ACEs as explicit entries.
  • Disable inheritance and drop inherited ACEs.
  • Enable inheritance again.
  • Add permissions.
  • Remove permissions.
  • Review the predicted final SDDL before applying.

Inspection Examples

Show current ACL

python3 ntacl_tool.py show /srv/shares/finance/private

Show JSON output

python3 ntacl_tool.py show /srv/shares/finance/private --json

Useful for integration with shell scripts, automation, and auditing pipelines.

Inheritance Control

Disable inheritance and keep inherited entries

python3 ntacl_tool.py set /srv/shares/finance/private \
  --disable-inheritance \
  --dry-run

Disable inheritance and remove inherited entries

python3 ntacl_tool.py set /srv/shares/finance/private \
  --disable-inheritance \
  --drop-inherited \
  --dry-run

Enable inheritance again

python3 ntacl_tool.py set /srv/shares/finance/private \
  --enable-inheritance \
  --dry-run

In the current implementation, enabling inheritance removes DACL protection. Existing explicit ACEs remain in place.

Permission Changes

Add modify access

python3 ntacl_tool.py set /srv/shares/finance/private \
  --add "principal=DOMAIN\\alice,perm=modify,flags=OICI,type=A" \
  --dry-run

Add full control to Domain Admins and apply

python3 ntacl_tool.py set /srv/shares/finance/private \
  --add "principal=DA,perm=full,flags=OICI,type=A" \
  --apply

Add a deny ACE

python3 ntacl_tool.py set /srv/shares/finance/private \
  --add "principal=DOMAIN\\tempuser,perm=read,flags=OICI,type=D" \
  --dry-run

Removing Entries

Remove by list index

python3 ntacl_tool.py set /srv/shares/finance/private \
  --remove-index 2 \
  --dry-run

Remove by principal and ACE type

python3 ntacl_tool.py set /srv/shares/finance/private \
  --remove "principal=DU,type=A" \
  --dry-run

Remove by SID and mask

python3 ntacl_tool.py set /srv/shares/finance/private \
  --remove "sid=S-1-5-21-100-200-300-400,mask=0x001200a9" \
  --dry-run

Remove only inherited entries matching a filter

python3 ntacl_tool.py set /srv/shares/finance/private \
  --remove "principal=DOMAIN\\contractors,inherited=yes" \
  --dry-run

Wide Examples

Prepare a finance folder for custom ACLs

python3 ntacl_tool.py set /srv/shares/finance/private \
  --disable-inheritance \
  --drop-inherited \
  --add "principal=DA,perm=full,flags=OICI,type=A" \
  --add "principal=DOMAIN\\finance-managers,perm=modify,flags=OICI,type=A" \
  --add "principal=DOMAIN\\finance-readers,perm=read,flags=OICI,type=A" \
  --dry-run

Apply the same ACL plan for real

python3 ntacl_tool.py set /srv/shares/finance/private \
  --disable-inheritance \
  --drop-inherited \
  --add "principal=DA,perm=full,flags=OICI,type=A" \
  --add "principal=DOMAIN\\finance-managers,perm=modify,flags=OICI,type=A" \
  --add "principal=DOMAIN\\finance-readers,perm=read,flags=OICI,type=A" \
  --apply

Re-enable inheritance after a temporary lockdown

python3 ntacl_tool.py set /srv/shares/finance/private \
  --enable-inheritance \
  --apply

Operational Notes

  • The tool warns if DA does not end up with full control in the final ACL.
  • Name resolution depends on wbinfo.
  • ACL parsing is pragmatic, not a full SDDL implementation.
  • Always start with show or --dry-run before using --apply.
