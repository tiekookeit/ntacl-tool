ntacl_tool

Utilitário de linha de comando para inspecionar e alterar ACLs NT via Samba, com fluxo interativo e também execução direta por parâmetros.

Manual / Guia Rápido

O Que É

O ntacl_tool lê e altera descritores de segurança NT em formato SDDL em caminhos gerenciados por Samba.

Use quando precisar de staging de ACL, mudanças seguras de permissão, controle de herança e automação por CLI.

Para Quem

Administradores de sistemas, operadores Samba/AD, responsáveis por file servers e quem automatiza ajustes de permissão em pastas.

Modos Principais

interactive para edição guiada.

show para consulta.

set para mudanças diretas e automação.

Por Que Esta Ferramenta Existe

Trabalhar com ACL NT diretamente em SDDL é preciso, mas pouco prático. O ntacl_tool cria uma camada operacional mais amigável sobre samba-tool ntacl get --as-sddl e samba-tool ntacl set.

Ele atende principalmente três necessidades:

  • Inspecionar a ACL atual em formato legível.
  • Alterar permissões com staging antes de aplicar.
  • Executar mudanças diretas por script sem abrir menu interativo.

Requisitos

  • python3
  • samba-tool do pacote samba-common-bin
  • wbinfo do pacote winbind
sudo apt update
sudo apt install -y python3 samba-common-bin winbind

Formato dos Comandos

ntacl_tool.py interactive CAMINHO
ntacl_tool.py show CAMINHO [--json]
ntacl_tool.py set CAMINHO [OPCOES]
O comando set não aplica alterações sem --apply. Use --dry-run para revisar a ACL final antes.

Modo Interativo

Use o modo interativo quando quiser um menu guiado e uma área de staging visível antes de aplicar as mudanças.

python3 ntacl_tool.py interactive /srv/shares/financeiro/privado

No menu você pode:

  • Desativar herança e manter ACEs herdadas como explícitas.
  • Desativar herança e remover ACEs herdadas.
  • Reativar herança.
  • Adicionar permissões.
  • Remover permissões.
  • Revisar a SDDL final prevista antes de aplicar.

Exemplos de Consulta

Mostrar a ACL atual

python3 ntacl_tool.py show /srv/shares/financeiro/privado

Mostrar a saída em JSON

python3 ntacl_tool.py show /srv/shares/financeiro/privado --json

Útil para integração com shell scripts, automação e trilhas de auditoria.

Controle de Herança

Desativar herança e manter entradas herdadas

python3 ntacl_tool.py set /srv/shares/financeiro/privado \
  --disable-inheritance \
  --dry-run

Desativar herança e remover entradas herdadas

python3 ntacl_tool.py set /srv/shares/financeiro/privado \
  --disable-inheritance \
  --drop-inherited \
  --dry-run

Reativar herança

python3 ntacl_tool.py set /srv/shares/financeiro/privado \
  --enable-inheritance \
  --dry-run

Na implementação atual, reativar herança remove a proteção da DACL. As ACEs explícitas existentes permanecem.

Alteração de Permissões

Adicionar acesso de modificação

python3 ntacl_tool.py set /srv/shares/financeiro/privado \
  --add "principal=DOMINIO\\alice,perm=modify,flags=OICI,type=A" \
  --dry-run

Adicionar controle total para Domain Admins e aplicar

python3 ntacl_tool.py set /srv/shares/financeiro/privado \
  --add "principal=DA,perm=full,flags=OICI,type=A" \
  --apply

Adicionar ACE de negação

python3 ntacl_tool.py set /srv/shares/financeiro/privado \
  --add "principal=DOMINIO\\tempuser,perm=read,flags=OICI,type=D" \
  --dry-run

Remoção de Entradas

Remover pelo índice da listagem

python3 ntacl_tool.py set /srv/shares/financeiro/privado \
  --remove-index 2 \
  --dry-run

Remover por principal e tipo de ACE

python3 ntacl_tool.py set /srv/shares/financeiro/privado \
  --remove "principal=DU,type=A" \
  --dry-run

Remover por SID e máscara

python3 ntacl_tool.py set /srv/shares/financeiro/privado \
  --remove "sid=S-1-5-21-100-200-300-400,mask=0x001200a9" \
  --dry-run

Remover apenas entradas herdadas que combinem com um filtro

python3 ntacl_tool.py set /srv/shares/financeiro/privado \
  --remove "principal=DOMINIO\\terceirizados,inherited=yes" \
  --dry-run

Exemplos Mais Amplos

Preparar uma pasta financeira para ACL customizada

python3 ntacl_tool.py set /srv/shares/financeiro/privado \
  --disable-inheritance \
  --drop-inherited \
  --add "principal=DA,perm=full,flags=OICI,type=A" \
  --add "principal=DOMINIO\\finance-managers,perm=modify,flags=OICI,type=A" \
  --add "principal=DOMINIO\\finance-readers,perm=read,flags=OICI,type=A" \
  --dry-run

Aplicar o mesmo plano de ACL de verdade

python3 ntacl_tool.py set /srv/shares/financeiro/privado \
  --disable-inheritance \
  --drop-inherited \
  --add "principal=DA,perm=full,flags=OICI,type=A" \
  --add "principal=DOMINIO\\finance-managers,perm=modify,flags=OICI,type=A" \
  --add "principal=DOMINIO\\finance-readers,perm=read,flags=OICI,type=A" \
  --apply

Reativar herança após um bloqueio temporário

python3 ntacl_tool.py set /srv/shares/financeiro/privado \
  --enable-inheritance \
  --apply

Notas Operacionais

  • A ferramenta emite um aviso se DA não terminar com controle total na ACL final.
  • A resolução de nomes depende de wbinfo.
  • O parser de ACL é pragmático; ele não implementa toda a especificação SDDL.
  • Sempre comece com show ou --dry-run antes de usar --apply.
